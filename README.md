🚀 AI Coding Documentation Assistant | RAG-Based Project

Excited to share my latest project — AI Coding Documentation Assistant, a RAG-based application designed to help developers get answers from their own coding documentation and knowledge base.

🔹 What it doesThe system allows users to:
📚 Build a knowledge base from Python, SQL, Machine Learning, Git, and API documentation

🔎 Retrieve relevant documentation using embeddings + vector search

🤖 Ask coding-related questions through an AI-powered chat interface

📄 Upload documents and add them to the knowledge base

💡 Get explanations, examples, and solutions based on the available documentation

🔗 View the source documents used for generating answers

🐙 Support the idea of ingesting a GitHub repository and answering questions about its code

🔹 Tech Stack
Frontend: React.js, Vite, CSS
Backend: Python, FastAPI
AI/ML: RAG, Embeddings, FAISS, LLM
Data: Python, SQL, ML, Git amp; API documentation

This project helped me understand how Retrieval-Augmented Generation (RAG) can be used to build practical AI applications that work with custom knowledge bases.

I'm continuing to improve the project with features such as document upload, code-error analysis, and GitHub repository understanding.
